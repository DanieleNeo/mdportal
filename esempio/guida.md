# Guida al portale

## Navigazione

Usa l'indice a sinistra per aprire i documenti e quello a destra per navigare tra le sezioni. Cerca con `/` oppure `Ctrl+K`. Il tema è modificabile dalla barra superiore.

## Esempio di codice

```python
from pathlib import Path
print(Path('docs.html').resolve())
```
